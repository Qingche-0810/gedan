# 歌单排序

给家里老人的 U 盘歌曲一键编号小工具。

- 打开 U 盘 → 歌全进来，旧编号自动剥掉
- 按名字 / 按歌手一键排，带 A 的（自己标过要靠前的）永远在最前
- 想微调就拖一拖，或者选中点「置顶」「上移」「下移」
- 「一键编号」把所有歌改成 `001-A巴哈尔古丽 - 最美的还是我们新疆.mp3` 这种三位数前缀
- 编号完顺手把 **U 盘里的播放顺序**也理好。很多音响、车机不看文件名，按歌拷进 U 盘的先后放，所以光改名没用、放出来还是老顺序；软件会把这一层目录的登记顺序理成列表的顺序（同一个盘里搬动只改登记、不拷数据，一瞬间）。文件名已经对的时候点「一键编号」也会问一句要不要只理顺序
- 「撤销上次编号」一键退回
- 「出歌单 txt」生成带日期时间的歌单并打开。**歌单默认存到桌面**；想存别处点旁边的「歌单存到：…」选一个文件夹，选过就记住，以后都存那儿
- 电脑显示设置缩放 125% / 150% / 175% 的也能用：窗口按屏幕封顶，窗口不够高时缩的是歌单列表，底下的按钮永远在

exe 在 Releases 里下：**gedan.exe**，双击就开，不用装任何东西。下载下来想改成「歌单排序.exe」随便改。

源码 `gedan.py`，纯 Python + tkinter。打包由 GitHub Actions 在 Windows 机器上自动完成。
