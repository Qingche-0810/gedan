# 歌单排序

给姥爷的 U 盘歌曲一键编号小工具。

- 打开 U 盘 → 歌全进来，旧编号自动剥掉
- 按名字 / 按歌手一键排，带 A 的（自己标过要靠前的）永远在最前
- 想微调就拖一拖，或者选中点「置顶」「上移」「下移」
- 「一键编号」把所有歌改成 `001-A巴哈尔古丽 - 最美的还是我们新疆.mp3` 这种三位数前缀
- 「撤销上次编号」一键退回
- 「出歌单 txt」生成带日期时间的歌单并打开

exe 在 Releases 里下，双击就开，不用装任何东西。

源码 `gedan.py`，纯 Python + tkinter。打包由 GitHub Actions 在 Windows 机器上自动完成。
